# 🚀 Documento do Projeto - Registro de Testes do Protótipo

Este repositório contém a estrutura do protótipo desenvolvido pelo grupo e o registro das observações feitas durante os testes com usuários.

---

## 💡 Aprendizados com os Testes do Protótipo

Após apresentar nosso protótipo para outro time e observar a interação, destacamos **dois aprendizados fundamentais**:

### 1. Clareza na Navegação Básica (O que funcionou bem)
* **Observação:** Notamos que a pessoa conseguiu identificar rapidamente onde clicar para navegar entre as telas principais.
* **Aprendizado:** A interface intuitiva funcionou como esperado, confirmando que a estrutura visual e os botões principais estavam bem posicionados e compreensíveis.

### 2. Dúvida na Funcionalidade Principal (Ponto de melhoria)
* **Observação:** O usuário hesitou e demonstrou dúvida na hora de entender a parte de cadastro de informações/ações do aplicativo.
* **Aprendizado:** Identificamos que essa seção precisa de uma explicação visual mais clara ou de um fluxo mais organizado (como textos de instrução mais simples ou ícones indicativos) para evitar confusão.
